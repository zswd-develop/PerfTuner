# PerfTuner
PerfTuner 是一款面向安卓玩机爱好者的调度工具，依赖 Root 权限运行。它支持自定义 CPU、GPU 调度参数、进程优先级以及性能档位，可按需调整设备性能输出，用来优化游戏帧率、控制发热，适合熟悉内核调度机制的用户。本应用不会窃取、上传用户隐私数据。
⚠️ 风险声明：本工具会修改系统底层调度参数，配置错误可能导致卡顿、闪退、死机、自动重启，极端情况会引发系统故障。使用本软件即代表你知晓全部风险，自愿承担所有后果；若出现死机、系统损坏等问题，开发者不承担任何责任。建议操作前备份重要数据，请在充分理解调度原理的基础上谨慎调试。
